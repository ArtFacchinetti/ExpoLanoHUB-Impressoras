# Histórico de versões

## 0.2.0 — 28/10/2026

- PostgreSQL com migrações versionadas do Prisma 7.
- Cadastro idempotente das impressoras configuradas.
- Coleta automática `FAST` e `NORMAL` com limite de concorrência.
- Persistência transacional do último status, eventos e métricas.
- API para consultar status, cadastrar impressoras e executar coleta manual.
- Preservação de campos não consultados e de valores brutos de suprimento.

## 0.1.0 — 28/10/2026

- Workspace Git, Docker Compose, API de saúde e teste de conectividade SNMP.
